# Učko Quiz
Android app (Kotlin, Jetpack Compose, Firebase) for 6th graders: Matematika, Angleščina, Naravoslovje. Every exercise is a mini game.

## Team
- Nikita M: infrastructure + backend (`data/`)
- Nikita F: frontend (`ui/`)
- Simona: games + UI/UX (`games/`)

## Git rules
- Never push to `main`. Work on a branch and open a pull request.
- Branch names: `backend/...`, `frontend/...`, `games/...`
- Commit messages: `feat:`, `fix:`, `chore:`, `docs:`
- Pull `main` before starting: `git pull origin main`
- One JSON file per lesson in `content/`
- Reviews: M reviews F, F reviews Simona, Simona reviews M
